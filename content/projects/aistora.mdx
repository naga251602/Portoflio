- Beat Pandas by **3x** on sort, group-by, and join operations across 100K+ row datasets with an in-memory columnar query engine in Python on Apache Arrow, with sub-second filtering and aggregation.
- Shipped a production-grade Flask REST API with JWT auth and RBAC for secure multi-tenant querying, backed by PostgreSQL with per-user schema isolation. Containerized with Docker Compose, **85% test coverage**, and CI/CD through GitHub Actions.
- Built a React dashboard with Recharts so non-technical users can query and visualize large datasets without writing SQL, going from raw data to insight in under 3 clicks.
