- Held **1,000+ WebSocket connections** on one Go instance at **sub-50ms** broadcast latency with a goroutine-per-room design, backed by Kafka event streaming, OpenTelemetry tracing, and Nginx sticky sessions.
- Rendered **8 live shader canvases at 60fps** in one spectating view by streaming code diffs instead of full sources and batching WebGL canvas updates.
- Recovered **95%+** of dropped sessions mid-round without state loss, using server-authoritative timers and snapshot-based resync.
