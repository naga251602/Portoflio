- Processed **$52,000+** in escrow-held payments across **140+ verified bookings** with zero payment discrepancies, using an idempotent escrow state machine on Stripe Connect webhooks.
- Held **sub-120ms p95 latency at 500 concurrent users** in k6 load tests, using Redis cache-aside, connection pooling, and composite PostgreSQL indexes.
- Cut fraudulent listings to **under 2%** of submissions with .edu email verification and lease-document checks, and hit **92% test coverage** on payment-critical paths as merge-blocking GitHub Actions checks.
