- Reached **80% test accuracy** on 2025 IPL match outcomes with a multi-modal deep learning framework built on performance data from 13 cricket leagues and 235 players, using league-quality weighting and recency decay.
- Designed a Dynamic OVR rating system (55 to 97 scale) feeding a 4-source weighted attention transformer with learnable fusion weights, capturing phase-specific batting (Top Order, Middle, Finisher) and bowling (Powerplay, Middle, Death) performance.
- Reached a **Brier score of 0.24** by combining a 2-layer Graph Attention Network for batter-bowler matchups with a 10,000-iteration Monte Carlo simulation engine, deployed as a Flask API with SHAP explainability at sub-2s latency.
