- Built an any-to-any database migration CLI that supports **6 SQL dialects** (PostgreSQL, MySQL, SQLite, SQL Server, MariaDB, OracleDB) with a single command.
- Used SQLAlchemy's cross-dialect layer to read the source schema (tables, columns, views), recreate it on the target, and move the data, handling dialect differences behind the scenes.
- Packaged it as a pip-installable Python CLI that only needs source and target connection URLs, with a pytest suite and an MIT License.
