# Socials data

**File:** `data/socials/index.json`

Top-level object with `github`, `linkedin`, `google_scholar`, `resume`, and dated `profiles` entries. URLs may be placeholders; do not treat ratings as live.

This must remain valid strict JSON. JSON does not permit comment headers, so usage instructions are kept here. Records are loaded by `lib/data_loader.js` and should not contain markup or executable source.

**Current entries:** one configuration object.
